# Grok 赛道分类器（Prompt 模板 + 使用说明）

> 用途：让 Grok Build 子代理对 KOSX 成员逐个访问 X 主页（bio + 帖子），一次输出
> **赛道 + 标签** 判断。分类走这个脚本/会话，不占 SocialData 额度（SocialData 只留给
> 结构化数据采集）。产物人工 review 后入库，赛道体系见 CONTRIBUTING「成员赛道分类」。
>
> 维护：五赛道定义有变动时同步更新本文件与 CONTRIBUTING。

## 使用方式

1. 打开 Grok Build（或 headless：`grok -p "$(cat docs/grok-track-classifier.md)" ...`）
2. 把下方「Prompt」整段粘贴，把 `成员handle列表` 替换成实际清单（一个 handle 一行）
3. 跑完后人工 review `confidence < 0.7` 的项，确认后交脚本入库

## Prompt（整段复制）

```
你是 KOSX 万粉影响力计划的赛道分类官。任务：对下面每位成员，访问他的 X 主页，
读取 bio 和最近帖子，判断他的【赛道】和【标签】，输出严格 JSON。

## 操作要求
- 对每个 handle，用 x_search 工具访问该博主主页（参数 allowed_x_handles=["该handle"]，
  query 请调取 bio 与最近帖子内容）。逐个处理，不要跳过。
- 判断依据：帖子内容权重为第一信号（看"他实际在发什么"），bio 为佐证。
  若 bio 与帖子冲突，以帖子为准（例：bio 自称交易员但帖子一半是 AI 工具分享，按帖子定）。
- 每个成员至少精读 5 条帖子再下结论；帖子太少或几乎为空的，按 bio 判断并降低置信度。

## 赛道体系（一人可挂 1-3 个，按内容主线排序）

1. AI工具：不写代码，靠 AI 工具落地/培训/服务/分享。
   信号：AI 工具分享与实测、Codex 实战、AI 工作流/提示词、AI 培训或课程、本地模型/知识库、
   AI 变现、AI 应用教程。
2. 财经：美股/加密/交易/宏观。
   信号：美股、期权、SPX、web3、crypto、链上、交易系统、宏观/利率、投资研究、复利。
3. 开发者：写代码/造产品/SaaS/Indie Hacker。
   信号：编程、full-stack、开源项目、SaaS、Indie Hacker、Build in Public、上线产品、
   技术架构、Engineer/PhD in CS。
4. 增长：自媒体/做号/营销/运营。
   信号：自媒体、涨粉、流量、账号运营、创作者、营销、内容增长、社群运营。
5. 出海：跨境/华语 X 出海。
   信号：跨境电商（亚马逊/Temu/Shein）、出海工具、海外市场、华语创作者做海外内容。
6. 综合：无法明确归入以上任何赛道，或信号过弱/过于混杂时归此赛道。综合是过渡桶，
   不要轻易使用——只有确实定不了才归综合。

## 标签（tags）要求
- 3-8 个，自由发挥，描述该博主的领域细节、身份、风格、人群。
- 例子：Agent、出海、00后、学生、前大厂、Building in Public、理财、医疗健康、
  跨境电商、美股、web3、设计、教育、副业、长期主义。
- 赛道（tracks）和标签（tags）可以重叠（如赛道=财经，标签含"web3"），但标签要更细。

## 置信度（confidence）
- 0-1 的浮点数，代表你对这条分类判断的把握。
- 帖子充分且信号清晰 ≥ 0.85；帖子少或信号模糊 0.6-0.8；非常模糊 < 0.6。
- 归「综合」的置信度 ≤ 0.65。

## 输出（严格 JSON，不要输出其他文字）
{ "members": [ { "handle": "xxx", "tracks": ["财经", "出海"], "tags": ["美股", "web3", "00后", "长期主义"], "confidence": 0.9, "note": "可选：一句话判断依据" } ] }

## 成员清单（handle 每行一个）
成员handle列表
```

## 输出校验

- 每个成员必须有 `tracks`（1-3 个）与 `tags`（3-8 个）
- 全部 `tracks` 必须来自上面的赛道枚举（含「综合」），出现别的新赛道名视为跑偏，需重跑
